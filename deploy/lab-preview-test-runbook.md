## Работа с владельцем сервера — по одному действию

**1. В PowerShell открыть SSH:**

```powershell
ssh root@77.233.212.200
```

Если пользователь сервера другой, заменить `root` на известный логин. Пароли и ключи не присылать в чат.

**2. В SSH только прочитать состояние (без изменений):**

```bash
cd /opt/bots/ege-blizko && printf 'BRANCH=' && git branch --show-current && printf 'HEAD=' && git rev-parse --short HEAD && printf 'DIRTY_FILES=' && git status --porcelain | wc -l && printf 'SERVICE=' && systemctl is-active ege-blizko
```

Если есть незакоммиченные изменения, **остановиться** и сохранить их отдельно, не выполнять `git reset --hard`.

**3. Уточнить, где хранится SQLite и где находятся резервные копии.**

Не раскрывать Telegram-токены, .env и другие секреты. Найти `COREAPP_DB_PATH` в конфигурации запуска и пути резервного копирования. Перед переключением ветки сделать консистентный SQLite backup через Python `sqlite3.Connection.backup()`, а также сохранить текущий git commit. Убедиться, что `.venv/bin/python` работает.

**4. Только после проверки бэкапа — установка ветки на Timeweb.**

- `git fetch origin feature/lab-preview-admin-20261010`;
- сохранить исходный commit;
- переключиться на точный commit тестовой ветки;
- `./.venv/bin/python -m compileall -q .`;
- **только при успешной компиляции** перезапустить `ege-blizko.service`;
- проверить `/health`, `/lab-app`, `/lab-preview-20261010` и журнал ошибок;
- при любой ошибке вернуть исходный commit и перезапустить сервис.

Рекомендуется выполнять эту фазу в интерактивном сопровождении, **не склеивая в одну команду**, чтобы не потерять рабочую версию.

**5. В Telegram открыть админский кабинет** и нажать `🧪 Лаборатория · ТЕСТ`. Проверить пять режимов и шесть тем с телефона. Ученикам новую кнопку не показывать.

## Ограничения доступа

Кнопка добавлена исключительно в админское меню. Однако тестовая HTML-страница представляет собой **публичную read-only демонстрацию**: человек со ссылкой может открыть её напрямую. В ней нет персональных данных и обращений к `/lab-app/api`. Если нужна серверная блокировка для всех, кроме владельца, перед общим релизом нужен отдельный механизм авторизации Telegram initData.

## Принцип отката

Пока тест не одобрен, **не менять маркер релиза и не переносить новую лабораторию в ученический хаб**. При откате на сервере вернуть сохранённый commit, перезапустить `ege-blizko.service`, проверить `/health`, исходную лабораторию и статистику.
