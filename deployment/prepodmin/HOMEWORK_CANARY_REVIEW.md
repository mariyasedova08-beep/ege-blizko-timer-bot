# ПРЕПАДМИН — закрытый пилот письменных ДЗ

Этот PR добавляет только ограничение области тестирования. Никаких изменений
боевой БД, конфигурации Nginx, systemd или S3 сам по себе не выполняет.

## Защитная схема

Даже если общий флаг TEACHER_PRODUCT_HOMEWORK_UPLOADS_ENABLED=1,
письменные ДЗ доступны ТОЛЬКО когда указаны два отдельных значения:

- TEACHER_PRODUCT_HOMEWORK_CANARY_TEACHER_ID=<id преподавателя>
- TEACHER_PRODUCT_HOMEWORK_CANARY_GROUP_ID=<id тестовой группы>

Оба значения должны быть положительными числами. Если хотя бы одно не задано,
режим письменного ДЗ запрещён, даже когда общий флаг включён.

Проверка применяется на сервере к созданию письменного ДЗ, загрузке файлов
и отправке работы на проверку. Назначение другой группе отклоняется. В интерфейсе
других групп письменный вариант будет недоступен.

## Как проверить без риска для настоящих учеников

1. До установки сохранить базу и проверить резервное копирование.
2. Убедиться, что тестовая группа содержит только вымышленные данные,
   без настоящих учеников/оплат/Telegram-рассылок.
3. После отдельного согласования объединить PR, пройти isolated CI,
   опубликовать код ПРЕПАДМИНА через guarded GitHub workflow.
4. В отдельных защищённых настройках PREPODMIN указать доступ к директории
   /opt/bots/prepodmin/data/homework_uploads и соответствующие два ID.
5. После отдельного подтверждения владельца включить глобальный флаг=1
   только при заполненных двух полях ограничения. Перезапустить только prepodmin,
   проверить доступность сайтов и active ege-blizko.
6. На **тестовой** группе проверить JPEG, PNG, PDF, черновик, отправку,
   «На проверке», замечание, повторную сдачу и «Проверено».
   Убедиться, что в другой группе файл загрузить и письменное ДЗ выдать нельзя.
7. Проверить, что копия новых тестовых файлов ушла в S3, что она
   восстанавливается с базой в отдельный каталог. Не менять боевую БД
   при проверке восстановления.
8. После теста выключить общий флаг или сбросить два ID канарейки,
   но не удалять ранее загруженные файлы/историю.

Важно: учитель может выдать ДЗ всей группе; использовать реальную учебную
группу для теста нельзя. Старые отметки тестов и существующие ДЗ сохраняются.

Без отдельного решения не включать функцию для всех учителей: необходимо
отдельное согласование правил хранения работ несовершеннолетних, защиты
ключей и мониторинга S3, а также продуктовых прав и интерфейса.
