Для обновления helper (связь SSH как root, из Windows PowerShell):

```powershell
ssh root@77.233.212.200 "git -C /opt/bots/ege-blizko fetch -q origin feature/timeweb-safe-deploy-20261012:refs/remotes/origin/feature/timeweb-safe-deploy-20261012 && echo FETCH_OK"

```

Обе команды **не перезапускают** Telegram-бота. Затем владелец вручную запускает GitHub Actions `Timeweb — EGE BLIZKO manual release` из ветки `feature/timeweb-safe-deploy-20261012`, подтверждает `timeweb-production` и смотрит `Success` и логи `DEPLOY SUCCESS`.

Серверный helper принимает только четыре перечисленных файла: копирует их из staging в собственную закрытую папку, проверяет синтаксис и набор вопросов, создаёт online backup SQLite и копии исходных файлов, затем меняет только эти файлы и перезапускает только `ege-blizko`. Проверяет `/health` и маркеры запуска нового тренажёра и ОГЭ, при сбое восстанавливает старый код, не откатывая автоматически работающую базу данных. Новые отдельные таблицы тренажёра создаются самим приложением при старте.

Рекомендуемая пользовательская проверка после выпуска: `/start specialsalts` в Telegram-боте; варианты 10/20/25/50, «Мои ошибки», «Моя статистика», а также прежние тренажёры ОГЭ и кабинет. Расссылки детям не отправлять без отдельного выбора преподавателя.

## Синхронизация Кулёчков, статистики и рейтинга — версия для проверки

Добавлено в `run_bot_production.py`: `install_ege11_rewards_and_stats_sync()`. **Пока не в продакшене**, нужно отдельное подтверждение GitHub Actions `Timeweb — EGE BLIZKO manual release` (`timeweb-production`). Без обновления серверного helper: все изменения работающего кода находятся в разрешённом `run_bot_production.py`, остальные разрешённые файлы из предыдущего релиза сохраняются.

### Принцип с даты назначения

- Преподаватель использует `Кабинет Маши → 📣 Тренажёры ЕГЭ · 11 класс`. Фокусные темы хранятся в `ege11_trainer_focus`; при первом обновлении новая таблица `ege11_reward_assignments` фиксирует текущие активные темы и время начала.
- При каждом нажатии на название темы в кабинете новая запись (включение) открывает временной интервал, выключение — закрывает. Переключать можно несколько раз за месяц.
- Для новых месячных норм считаются **только завершённые тренировки, попавшие в интервал назначения**. За 3 завершённые тренировки по одной назначенной теме — 1 Кулёчек.
- Если тема отключена до завершения 3 тренировок, невыполненная норма перестаёт быть обязательной. Уже заслуженный Кулёчек не снимается.
- При первом включении этого механизма сохраняется слепок **ранее заработанных за текущий месяц** Кулёчков за старые темы в отдельной `ege11_reward_legacy_credits`; их не отбираем. Месяцы до миграции используют прежние правила начисления. Ранее выбранные победители в `kulek_student_month_winners` не изменяются.
- Пауза рассылок не отменяет назначенные темы и связанные нормы Кулёчков; темы отключаются отдельной кнопкой.
- **Все завершённые тренировки**, в том числе старые темы, остаются видимыми в индивидуальной статистике, недельном прогрессе и месячных отчётах. Новые `hydroxides`, `middlesalts`, `specialsalts` входят в общее количество.
- Формулы «Ученик месяца» и общего рейтинга остаются прежними; компонент *регулярность тренажёров* использует именно назначенные темы. Личные карточки, месячные и общие отчёты читают общую систему.
- Данные учеников, финальных ДЗ, платежей, личных сессий тренажёров и Кулёчков не перезаписываются. Новые таблицы добавляются через `CREATE TABLE IF NOT EXISTS`.

5. Ничего не отправлять детям вручную при проверке; отправки в общий чат идут по прежним слотам расписания, ОГЭ9 не затронут.
