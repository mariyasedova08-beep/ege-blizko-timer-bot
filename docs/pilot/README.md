# Закрытый пилот лаборатории «ЕГЭ БЛИЗКО»

Подготовка 3 ноября 2026. Только изолированная лаборатория, без production и отправки приглашений.

## Первая подготовленная часть

В режиме «Урок» тестовой сборки: компактная отметка о тестовой версии; справка «Как начать»; явное предупреждение о сохранении доски в файл; статус локального сохранения PDF-пометок, в том числе при ошибке хранилища; скачиваемое сообщение о проблеме с версией сборки, реагентами, условиями, браузером и размером окна. Сообщение не отправляется автоматически. PDF, изображения, название файла, рукописные записи, токены и содержимое localStorage в диагностику не включаются. Описание вводит преподаватель самостоятельно.

Элементы пилота появляются только при data.preview=true. Производственный маршрут и сервер sandbox не менялись. Новая сборка подготовлена в feature-ветке, на Timeweb пока не установлена.

## Как начать преподавателю

1. Открыть тестовую ссылку, нажать «Как начать».
2. Загрузить небольшой PDF, написать формулу, сменить слайд и вернуться.
3. Попробовать доску, изображение, масштабирование, ластик и отмену.
4. Скачать проект доски и PDF с записями. Оригинальный PDF хранить отдельно.
5. При проблеме нажать «Сообщить о проблеме», описать шаги и скачать файл. Передать файл Марии выбранным способом; сама лаборатория его не отправляет.

Облачного сохранения сейчас нет. PDF-пометки сохраняются локально в текущем браузере и восстанавливаются после открытия соответствующего PDF. Редактируемую доску можно восстановить из скачанного проекта или локальной копии IndexedDB; дождитесь статуса сохранения перед закрытием. До начала живого урока преподаватель должен проверить свой планшет и браузер.

## Следующая часть: доступ по приглашению

Текущий тестовый URL открыт. До приглашений нужен отдельный шлюз доступа только на тестовом домене. Предлагаемый минимальный пилот: индивидуальная учётная запись на преподавателя, случайный пароль, серверное хеширование паролей, отзыв одного доступа без замены остальных. TLS обязателен; пароль/токен не помещается в URL. Все маршруты приложения и каталога должны проверять доступ, включая API; healthz без каталога можно оставить публичным. Отдельные тесты на обход путём, неверный/отозванный доступ, отсутствие секретов в логах. Конкретная реализация и установщик должны быть проверены на одноразовом сервере перед применением к sandbox. Глобальные SSH-политики, рабочие nginx-маршруты и production environments не менять.

Это проект следующего этапа, не установленная защита. Открытые GitHub/public HTTPS проверки после включения защиты потребуется адаптировать; не хранить пароли преподавателей в репозитории.

## Условия начала пилота

- Индивидуальный доступ установлен и проверен.
- Мария завершила реальный пробный урок на iMac/Wacom.
- PDF/проект сохраняются и открываются; ошибка хранилища заметна.
- Понимаем ограничение отсутствия автосохранения доски; для первых пробных занятий предусмотрено ручное сохранение. Перед широким пилотом приоритет — автоматическое восстановление доски с изображениями.
- Нет критических химических ошибок в контрольном наборе; пропущенные пары не выдаются за химическое отсутствие реакции.
- Преподавателям доступна справка и способ передать проблему.

Первый круг: 3–5 преподавателей, короткий пробный сеанс до использования на занятии с учениками. Приглашения никому не отправлены. К выпуску для чужих живых уроков пока не готово: доступ и восстановление доски остаются открытыми пунктами.

## Второй этап: вход и восстановление (кандидат)

Все дальнейшие изменения собираются в этой же ветке `feature/lab-review-board-20261101`, PR #102 остаётся черновиком. Рабочая лаборатория, бот и ПРЕПАДМИН вне области изменений.

### Восстановление доски

Полная сериализация проекта версии 2 хранится в IndexedDB: листы, имена, активный лист, координаты и масштаб, штрихи, изображения и листы импортированного PDF. Сохранение через 650 мс после перерисовки, статус успеха только после завершения транзакции. При повторном открытии пользователь выбирает восстановление или начало без старой копии; до выбора прежняя копия не перезаписывается. Повреждённый проект не заменяет текущую работу. Ошибка/переполнение показываются явно. При конфликте ревизий из другой вкладки запись блокируется, предлагается скачать свой проект. Ключ копии учитывает пилотную учётную запись. Это локальное восстановление в том же профиле браузера, не облачная синхронизация; очистка данных/приватный режим/аварийное закрытие до окончания записи могут привести к потере последних изменений. Ручной экспорт проекта остаётся необходимой резервной копией.

### Индивидуальный доступ

`deploy/lab_sandbox_server.py --access-file ...` закрывает HTML и API через HTTP Basic Auth за существующим HTTPS. Учётные записи со случайным паролем, солью и scrypt-хешем создаются `deploy/lab_pilot_access.py`; пароли не хранятся в файле и не передаются в URL. Доступ истекает по сроку или отзывается индивидуально; конфигурация читается заново для каждого запроса. Повреждённый/удалённый настроенный файл не открывает приложение. Публичный healthz содержит только техническое состояние и хеши, без каталога/материалов.

Утилита не отправляет приглашений и не перезапускает сервисы. Флаг `--activate` под root подготавливает только отдельный drop-in для `ege-lab-sandbox-preview.service`: фиксированный ExecStart с `--access-file`. Старый сервер, не умеющий этот флаг, после отката не запустится, вместо незаметного открытия доступа. Для активации позже потребуется отдельный проверенный шаг daemon-reload/restart исключительно этого sandbox-сервиса. Глобальные SSH/nginx-настройки не изменяются. До установки и публичного подтверждения 401/успешного входа защита считается неподключённой.

HTTP Basic сохраняет вход в браузере; для смены пользователя на общем компьютере нужен отдельный профиль/приватное окно. Уже скачанный каталог/проект невозможно отозвать удалённо. Это решение для небольшого закрытого пилота, не система подписок/оплаты и не защита от копирования.

Пример будущего администрирования (НЕ выполнялся на сервере): `python3 deploy/lab_pilot_access.py add teacher_01 --days 14 --activate`. Пароль показывается один раз в консоли администратора. Отзыв: `python3 deploy/lab_pilot_access.py revoke teacher_01`. Реальных учётных записей в ходе разработки не создано.
