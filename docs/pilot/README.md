# Закрытый пилот лаборатории «ЕГЭ БЛИЗКО»

Подготовка 3 ноября 2026. Только изолированная лаборатория, без production и отправки приглашений.

## Первая подготовленная часть

В режиме «Урок» тестовой сборки: компактная отметка о тестовой версии; справка «Как начать»; явное предупреждение о сохранении доски в файл; статус локального сохранения PDF-пометок, в том числе при ошибке хранилища; скачиваемое сообщение о проблеме с версией сборки, реагентами, условиями, браузером и размером окна. Сообщение не отправляется автоматически. PDF, изображения, название файла, рукописные записи, токены и содержимое localStorage в диагностику не включаются. Описание вводит преподаватель самостоятельно.

Элементы пилота появляются только при data.preview=true. Производственный маршрут и сервер sandbox не менялись. Новая сборка подготовлена в feature-ветке, на Timeweb пока не установлена.

## Как начать преподавателю

1. Открыть тестовую ссылку, нажать «Как начать».
2. Загрузить небольшой PDF, написать формулу, сменить слайд и вернуться.
3. Попробовать доску, изображение, масштабирование, ластик и отмену.
4. Скачать проект доски и PDF с записями. Оригинальный PDF хранить отдельно.
5. При проблеме нажать «Сообщить о проблеме», описать шаги и скачать файл. Передать файл Марии выбранным способом; сама лаборатория его не отправляет.

Облачного сохранения сейчас нет. PDF-пометки сохраняются локально в текущем браузере и восстанавливаются после открытия соответствующего PDF. Редактируемая доска восстанавливается из скачанного проекта; автоматического восстановления после закрытия пока нет. До начала живого урока преподаватель должен проверить свой планшет и браузер.

## Следующая часть: доступ по приглашению

Текущий тестовый URL открыт. До приглашений нужен отдельный шлюз доступа только на тестовом домене. Предлагаемый минимальный пилот: индивидуальная учётная запись на преподавателя, случайный пароль, серверное хеширование паролей, отзыв одного доступа без замены остальных. TLS обязателен; пароль/токен не помещается в URL. Все маршруты приложения и каталога должны проверять доступ, включая API; healthz без каталога можно оставить публичным. Отдельные тесты на обход путём, неверный/отозванный доступ, отсутствие секретов в логах. Конкретная реализация и установщик должны быть проверены на одноразовом сервере перед применением к sandbox. Глобальные SSH-политики, рабочие nginx-маршруты и production environments не менять.

Это проект следующего этапа, не установленная защита. Открытые GitHub/public HTTPS проверки после включения защиты потребуется адаптировать; не хранить пароли преподавателей в репозитории.

## Условия начала пилота

- Индивидуальный доступ установлен и проверен.
- Мария завершила реальный пробный урок на iMac/Wacom.
- PDF/проект сохраняются и открываются; ошибка хранилища заметна.
- Понимаем ограничение отсутствия автосохранения доски; для первых пробных занятий предусмотрено ручное сохранение. Перед широким пилотом приоритет — автоматическое восстановление доски с изображениями.
- Нет критических химических ошибок в контрольном наборе; пропущенные пары не выдаются за химическое отсутствие реакции.
- Преподавателям доступна справка и способ передать проблему.

Первый круг: 3–5 преподавателей, короткий пробный сеанс до использования на занятии с учениками. Приглашения никому не отправлены. К выпуску для чужих живых уроков пока не готово: доступ и восстановление доски остаются открытыми пунктами.

## Проверки первого этапа

GitHub Actions 41602078706: модульный этап и полный браузерный этап успешно пройдены. Браузерный набор проверяет два размера окна (1440×1000 и 820×1180), открытие/закрытие справки, скачивание и состав диагностики, восстановление PDF-пометок и явную ошибку при переполнении localStorage, а также существующие сценарии химии, доски и презентации. Локально 89 тестов: два пропуска из-за отсутствия nginx. Локальный браузерный прогон недоступен из-за отсутствия Chromium и неудачной загрузки браузера; подтверждение браузерных сценариев получено на одноразовом GitHub runner. Safari/Wacom и iPad пока требуют живой проверки.
