# Ручка, маркер, уровень раствора и экспорт PDF

Кандидат от 3 ноября 2026, сборка `78e0740c758142ce`. Изолированная ветка пилота, на Timeweb ещё не установлен.

- Новые штрихи ручки используют центростремительную интерполяцию через стабилизированные точки. Повторное изменение формы после отрыва исключено для новых штрихов. Старые записи/проекты используют прежний рендерер. Признак renderVersion=2 сохраняется в проектах и восстановительных копиях.
- Маркер получил собственную стабилизацию, независимо от настройки сглаживания ручки. Прямая линия не фильтруется. В экспортируемом PDF весь штрих рисуется одним прозрачным контуром: стыки отдельных сегментов больше не накапливают непрозрачность. Два разных штриха по-прежнему могут накладываться друг на друга.
- Первая порция жидкости занимает 36% высоты, последующие добавляют по 18%, предел 84%. Это визуальные порции, не вычисление миллилитров по стехиометрии. Реакция сама не уменьшает уже налитый уровень; очищение пробирки сбрасывает его. Сценарий получения хромата из Cr(OH)₃/H₂O₂ в щелочной среде проверяется отдельно.
- Кнопка PDF немедленно блокируется от повторного запуска и показывает ход подготовки. Базовые страницы текущего PDF кэшируются (до 24 МиБ), повторное сохранение не растрирует их заново. Перед экспортом создаётся снимок записей; кнопка восстанавливается и при ошибке. На больших документах первое сохранение всё ещё требует времени.

Проверки: существующий модульный набор; браузерные регрессии на сохранение петель/точек штриха, отсутствие повторной деформации, дрожание маркера, равномерность прозрачности экспортированного PDF по пикселям, индикатор/повторный запуск/кэш экспорта и уровень хромата при переключении пробирок. Ощущение пера на физическом Wacom/Safari автотестами не подтверждается — его оценивает владелец после установки. Production и учётные записи не меняются.
