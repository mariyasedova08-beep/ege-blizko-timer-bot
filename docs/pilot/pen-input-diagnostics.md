# Проверка входных событий пера

3 ноября 2026. В полученной диагностической пробе Safari передал mouse-события с постоянным давлением .5 при рисовании и нулём при отпускании; это не данные реального нажима. «Красивое письмо» было выключено, что влияет на текущий профиль. Значение ожидания кадра не измеряет полную аппаратную задержку. Эти наблюдения сами по себе не доказывают причину неудобного почерка.

В сборщике найдена собственная ошибка: конечная coalesced-точка иногда совпадает с родительским PointerEvent и записывалась повторно. В кандидате e8efff7bf8df3f04 исключаются только точные повторы x/y/t/pressure; настоящие более поздние неподвижные точки и изменение давления сохраняются. Для baseline сохраняется обработка pointerup, даже если raw-точка повторилась. Добавлен счётчик исключённых дублей. Ручка урока и параметры сглаживания не менялись.

Регрессия использует синтетический повтор coalesced/parent event в активном pen-потоке. Личные рукописные точки в репозиторий не добавлялись. Следующая полезная физическая проверка — тот же экран и вариант ровной толщины в Microsoft Edge на том же iMac/Wacom. Это сравнение браузерного входа; наличие настоящего нажима и комфорт в Edge на macOS заранее не гарантируются. Тестовый сайт пока сохраняет ранее установленную сборку ba45f4f8478808c0; исправление сборщика подготовлено в общей ветке пилота.
