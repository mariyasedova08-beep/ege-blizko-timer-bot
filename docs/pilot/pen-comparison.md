# Отдельная проба ручек

Кандидат от 3 ноября 2026, сборка `ba45f4f8478808c0`. Добавляется только при сборке изолированного sandbox, через кнопку «Проверить ручку» в панели пилота. Основная ручка урока, PDF-пометки и проекты доски не меняются.

## Сценарий

Написать имя/формулу в одном поле, затем переключить три варианта или включить «Сравнить рядом». Все варианты показывают одну и ту же записанную траекторию. Толщина и цвет выбираются для последующих штрихов. Отмена, очистка и закрытие/повторное открытие окна не затрагивают урок. Проба сохраняется в памяти до обновления страницы; скачивание JSON выполняется только явной кнопкой. Кнопка «Этот вариант удобнее» отмечает предпочтение в отчёте, не применяет профиль к уроку.

1. Текущая — существующий стабилизатор/завершение/рендерер лаборатории.
2. Плавная, ровная толщина — perfect-freehand, thinning=0, smoothing=.7, streamline=.55.
3. Плавная, с нажимом — perfect-freehand, thinning=.35, smoothing=.65, streamline=.45. Данные нажима используются для pen-событий с положительными значениями, отличающимися от стандартного .5; иначе применяется имитация по движению. Это эвристика выбора источника, не доказательство возможностей драйвера.

Диагностика показывает тип указателя, диапазон/число значений давления, число точек и coalesced samples. Время ожидания кадра измеряется внутри браузера, не является полной задержкой пера. Давление не используется как порог начала письма. Объём пробы ограничен 100 штрихами/60000 точками.

Выгружаемый JSON содержит только пробные штрихи, настройки/выбор профиля, технические данные браузера и окна. Файлы PDF, записи урока, токены и пароли не включаются. Ничего не отправляется автоматически. Ориентир пользователя — комфорт письма тем же Wacom в PDF Microsoft Edge на Windows; ощущения на iMac/Safari нужно оценить на физическом устройстве.

## Зависимость

perfect-freehand 1.2.3, MIT, исходный проект https://github.com/steveruizok/perfect-freehand . npm-архив проверен по SHA512 integrity; CJS-файл, лицензия и provenance сохранены в vendor/perfect-freehand. В браузер встраиваются локальный код и полный текст лицензии; сеть для движка не требуется. Библиотека и шаблон включены в хеши сборки. Обновление зависимости требует отдельного пересмотра.

## Проверки

99 модульных проверок, два локальных пропуска nginx. Браузерные проверки подготовлены для пен-событий с переменным давлением, трёх вариантов, параллельных миниатюр, экспорта одинаковых исходных точек, mouse fallback, отмены/очистки/закрытия и неизменности исходного урока. Установка на Timeweb ещё не выполнена.
