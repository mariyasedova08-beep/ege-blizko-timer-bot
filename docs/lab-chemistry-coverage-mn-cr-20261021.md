# Срочная ревизия химической базы лаборатории — 21.10.2026

Цель: использовать одну химически проверенную базу для самостоятельных опытов и режима «Урок + лаборатория». Не смешивать с LMS, ПРЕПАДМИНОМ, ученическими оповещениями или другими ботами.

## Найденные пробелы в выпускной базе

- В `ege_lab_substances.py` уже есть KMnO₄, K₂Cr₂O₇, K₂CrO₄, MnO₂, Cr₂O₃, CrO₃, Cr(OH)₃.
- В `ege_lab_inorganic_reactions.py` найдена одна запись с хроматом: K₂CrO₄ + H₂SO₄ (жёлтый → оранжевый); почти нет окислительно-восстановительных реакций с перманганатом, дихроматом и хроматом.
- В последнем проверенном превью урока до общей базы отдельно подготовлены некоторые реакции KMnO₄ + Na₂SO₃ и KMnO₄ + H₂O₂ с явным выбором среды. **Не считать их внесёнными в общий серверный реестр**.

## Порядок расширения

1. **Перманганаты (Mn +7), хроматы/дихроматы (Cr +6):** отдельные среды, восстановители, температура, концентрация и избыток. Подтверждённые полные молекулярные уравнения, коэффициенты, электронные балансы, степени окисления и наблюдаемые признаки. Нельзя автоматически переносить исход из одной среды в другую.
2. **Обмен:** кислоты + основания/оксиды/соли; соли + основания/соли; выпадение осадков, газы, образование слабого электролита; учитывать растворимость и исключения, амфотерные гидроксиды (Al(OH)₃ и Cr(OH)₃ — нерастворимы), выделение NH₃ из солей аммония.
3. **Замещение:** металлы + растворы солей с учётом ряда активности, пассивации, конкурирующей реакции с водой и состава раствора; газовыделение/растворение металла/отложение металла и цвета растворов.
4. **Контроль качества:** для каждой реакции тест на реестр веществ, баланс элементов/зарядов, химическую обоснованность и условия, визуальные признаки; отдельные критерии для неоднозначных/зависящих от концентрации реакций.

## Модель данных

Реакция: `reagents`, `medium`, `condition`, `temperature`, `excess`, `equation`, `oxidizer`, `reducer`, `electron_balance`, `solution_color`, `precipitate_color`, `gas_color`, `gas_smell`, `sign`, `source_status`.

Не «разрешать всё математическим генератором»: если нет проверенной реакции для комбинации и среды, интерфейс показывает «нужна проверка». Изменения только в отдельной ветке, работающий бот остаётся неизменённым до тестов и отдельного разрешения.
