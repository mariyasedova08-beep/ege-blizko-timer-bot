# Подсказки о нагревании, 02.11.2026

Для известной реакции, требующей нагрева, до запуска опыта показывается: «Эта реакция есть в базе — нужен нагрев. Нажми кнопку “🔥 Нагрев”». Кнопка выделена рамкой и розовым фоном, снабжена aria-describedby; подсказка имеет role=status. Дополнительные условия из каталога показаны рядом.

Урок: подсказка появляется сразу после выбора пары/среды, а также для следующего реагента в цепочке; если путь без нагрева существует, требование не показывается. После включения нагрева, смены пары или очистки подсказка снимается. Если опыт ещё не проводился, пользователь явно нажимает «Провести». Нагрев автоматически не включается.

Свободная лаборатория: подсказка рядом с нагревом выбранной пробирки, включая случай, когда следующий реагент требует предварительного нагрева и повторного добавления.

Исправлен поиск ожидающего нагрева этапа цепочки: он больше не теряется из-за отбора только текущих холодных реакций. Уже выполненный горячий этап не выдаётся за всё ещё ожидающий нагрева. Превращение, газ и растворение по-прежнему заблокированы до выполнения условий.

Браузерные сценарии: подсказка до опыта; концентрированная HCl; выделение Cl₂ только после нагрева; снятие подсказки; отсутствие ложного требования для HCl+NaOH, пары без реакции и Br₂+NaOH с доступным холодным вариантом. Изменения подготовлены в тестовой ветке; публичный сайт автоматически не обновляется, production не изменяется.
