# Закрытая Python-копия для изолированной проверки

Подготовка отдельная от PR #64. Тренажёр не устанавливается и не публикуется.
Передача пока не выполнялась; полный стенд не создавался.

## Состав и границы

Ранее разрешённая закрытая инвентаризация 39770956980 содержит 167 Python-модулей
общим размером 2 523 736 байт. Отпечаток канонического списка имён, размеров и
SHA-256 закреплён в seal_ege_python_snapshot.py; частные имена в публичном коде
не перечислены. 23 модуля отсутствуют в GitHub. Старый отчёт не гарантирует,
что все модули VPS сохранились с тех пор.

Механизм сначала повторяет прежнюю статическую инвентаризацию в памяти на VPS,
затем сверяет точное число и отпечаток модулей. После этого читает только эти
.py через дескрипторы с O_NOFOLLOW, сверяя размер, SHA-256 и изменение во время
чтения. Любая перемена блокирует копию. Автоматической замены ожидаемых хешей нет.
При дрейфе нужна новая read-only инвентаризация и отдельный просмотр различий.

Содержимое .env, SQLite/WAL, JSON, документов и других ресурсов не читается
и не копируется. Старый статический анализ читает метаданные ресурсов.
Python-файлы не исполняются и могут содержать встроенные константы:
их точная копия остаётся конфиденциальной, шифрование не является очисткой секретов.

Пакет шифруется на VPS в памяти для существующего закреплённого сертификата.
В GitHub передаётся только CMS AES-256-GCM, artifact хранится один день.
На VPS ничего не записывается; импорта приложения, service restart и sudo нет.
Передача использует только прежнюю python3 - --mode remote. Отказ серверного
ограничителя не обходится и не является разрешением менять его права.

## Запуск

PR проверяется без секретов/SSH. Слияние ничего не запускает. Реальная передача
доступна только ручным workflow_dispatch на main от владельца, после ранее
проверенной расшифровки тестового CMS и ручного допуска ege-lab-production.
Сверяются хост, ограниченный ege-deploy, ключ хоста, сертификат/его срок и
три скрипта, передаваемые по stdin. Открытые исходники/ошибки SSH не логируются.

## Локальная проверка

8 синтетических тестов: состав только Python, отсутствие исполнения и данных,
предел размера, изменённый список/хеш/тип файла, симлинк/FIFO, изменение при чтении,
закрепление скриптов и сертификата, фиксированная SSH-команда, прекращение
при ошибке транспорта, запись только шифротекста с 0600.
Настоящий SSH в тестах заменён. Шифрование — прежний проверенный CMS-упаковщик.

Неизвестные зависимости, пакеты и динамические пути остаются ограничением
статического анализа. complete_runnable_snapshot намеренно всегда false.
