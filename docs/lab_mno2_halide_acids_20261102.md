# MnO₂ как окислитель: HCl и HBr, 02.11.2026

Обе пары уже находились в PDF_EXTRA_REACTIONS импортированного каталога. Новые дубли не добавлялись. Уточнены признаки расходования тёмного твёрдого MnO₂, условия и учебные метаданные окислителя/восстановителя.

- MnO₂ + 4HCl(конц.) → MnCl₂ + Cl₂↑ + 2H₂O. В симуляторе сохранён нагрев: до него не показываются растворение и газ. При нагреве — расходование MnO₂, пузырьки и жёлто-зелёный Cl₂.
- MnO₂ + 4HBr → MnBr₂ + Br₂ + 2H₂O. Обязательный нагрев не вводится. Показаны расходование оксида и оранжево-бурая окраска брома; газовые пузырьки не добавляются.

В карточках: MnO₂ (Mn(+4) → Mn(+2)) — окислитель; HCl/Cl(−1) или HBr/Br(−1) — восстановитель. Есть раскрывающийся электронный баланс. Для урока MnO₂ находится по «оксид марганца 4», «оксид марганца (4)», «диоксид марганца» и формуле.

Источники: демонстрационный эксперимент КФУ https://kpfu.ru/portal/docs/F_1229691748/Demonstracionnyj.khimicheskij.eksperiment.pdf ; официальный учебный материал ИРО Ростовской области https://dpo.iro61.ru/upload/parse/giya/1061/giya9/khimiya.pdf ; потенциалы полуреакций Purdue https://chemed.chem.purdue.edu/genchem/topicreview/bp/ch20/electro.php .

Проверки: баланс атомов полного каталога, отсутствие дублей обеих пар, метаданные ОВР и отдельные условия; браузер — поиск MnO₂, отсутствие преждевременной анимации с HCl, нагрев, газ Cl₂, окраска без пузырьков с HBr, электронный баланс. Изменения только в тестовой ветке. Публичная сборка автоматически не обновляется, production не изменяется.
