# ЕГЭ БЛИЗКО · покрытие реакций обмена · этап 1

**Статус:** ветка для проверки, не развернута на Timeweb. Рабочего Telegram-бота не затрагивать.

## Зачем

Каталог до сих пор состоял преимущественно из отдельно перечисленных уравнений. Отсутствие пары в массиве не означало, что реакция невозможна. Цель — получить **воспроизводимую химическую модель**, которая покрывает комбинации всех поддерживаемых веществ и не придумывает реакции без движущей силы.

## Что делает `ege_lab_exchange_matrix.py`

- Соли + соли в водных растворах: положительный результат, когда по тщательно ограниченной таблице выпадает осадок.
- Соли + растворы щелочей: выпадение гидроксидов или других малорастворимых солей, включая голубой Cu(OH)₂, зелёный Fe(OH)₂, бурый Fe(OH)₃ и зелёный Cr(OH)₃.
- Соли аммония + щёлочи: образование NH₃.
- Кислота + щёлочь: нейтрализация с образованием H₂O.
- Кислоты + соли: осаждение (AgCl, BaSO₄, PbI₂), выделение CO₂, SO₂ или H₂S при взаимодействии с подходящими солями.
- Кислоты + твёрдые гидроксиды и основные оксиды: нейтрализация с корректным соотношением реагентов.
- Подкисление растворимых силикатов: H₂SiO₃↓.
- Совместный гидролиз солей Al(III), Cr(III), Fe(III) с подходящими карбонатами, сульфитами, сульфидами и кислыми солями; Fe(III) + сульфит/сульфид **не** считается обычным гидролизом.
- Cu(II) + карбонат: осадок основной соли Cu₂(OH)₂CO₃, а не выдуманного CuCO₃.
- Проверенные смеси ионов без движущей силы (NaCl + KNO₃) показывают «реакция не идёт», а не «неизвестно».

**Приоритет:** исходные химически проверенные записи, варианты избытка, хромат/дихромат, перманганат и реакции ОВР всегда важнее общего генератора. Для одной пары не добавляются две противоречащие друг другу записи.

## Ограничения

«Все» означает **все надежно определяемые случаи в поддерживаемом списке ЕГЭ**, а не обещание механически породить реакцию между любыми двумя веществами. Не классифицируем как обычный обмен:
- Fe(III) + S²⁻ / SO₃²⁻ / I⁻; Cu(II) + I⁻, взаимодействия HI с Fe(III) и Cu(II) — это химические ОВР со своей проверенной записью;
- Избыток/недостаток амфотерной щёлочи, комплексообразование, сильные кислоты-окислители — должны быть отдельными условиями;
- Растворимость, требующая конкретной температуры/концентрации/рН, не заменяется безусловной реакцией;
- Неизвестные пары не объявляем автоматически «реакция не идёт».

**Неизменные инварианты:** гидроксиды Al(III), Cr(III) нерастворимы в воде; осадки BaSO₄ — белые, AgI и PbI₂ — жёлтые, Cu(OH)₂ — голубой. Цвета подтверждать по химическому справочнику, а не по случайной палитре.

## Тестирование

`tests/test_lab_exchange_matrix.py`: проверка всех автоматически сгенерированных уравнений по числу атомов каждого элемента, наличия исходных веществ, уникальности пар, отрицательных случаев, отдельных солей и избытков. Тесты запускаются в GitHub Actions без подключения к работающему боту.

`tests/prepare_lab_medium_live_fixture.py` и `tests/check_lab_medium_live.mjs`: проверка тех же данных через **реальный HTML лаборатории** в Chromium при ширине экрана 920 и 1440 пикселей, включая PDF-режим и основную пробирку. Не использовать страницу offline preview как доказательство того, что production обновлен.
