# Стабилизация пера — тестовый кандидат 2026-11-02

Сборка `a21cb18b56a95b4a`. Подготовлена для изолированной лаборатории; установка на VPS пока не подтверждена.

Добавлена адаптивная стабилизация ручки во время движения: сильнее на медленных участках, слабее на быстрых. Отставание ограничено 1,5 CSS-пикселя, точка отрыва сохраняется. Состояние фильтра не попадает в сохранённые проекты. Сглаживание после отрыва сохранено. Маркер, прямая линия и выключенное «Красивое письмо» сохраняют прежний ввод. Масштаб учитывается в экранных координатах. Распознавания или замены букв нет.

Проверено: 87 модульных тестов, из них два локально пропущены из-за отсутствия nginx; 1383 уравнения/стадии сбалансированы. Полный браузерный набор прошёл при 1440×1000 и 820×1180, DPR 2. Синтетические проверки подтверждают уменьшение дрожания, ограничение отставания, сохранение окончания, независимость от масштаба. Это не физический тест Wacom: комфорт на планшете предстоит проверить пользователю.

Рабочий бот, ПРЕПАДМИН и production не изменялись. Изменения опубликованы только в feature-ветке, PR остаётся черновиком. Для обновления используется существующий установщик sandbox с резервной копией и откатом; HTTPS-конфигурацию менять не требуется.
