# Письмо и инструменты: тестовая ветка, 02.11.2026

Замечания преподавателя: усилие при письме, скачки букв, неудобные кнопки, потеря раздельных цветов ручки и маркера.

Изменения:
- Убрана задерживающая фильтрация координат, зависящая от пройденного расстояния. Сохраняются измеренные позиции пера и coalesced samples, кроме дублей менее 0,15 CSS px. Последнее положение фиксируется при отпускании. Сглаживание изображения и экспорта остаётся общим, без зависимости от нажима.
- Доска рисует backing bitmap с devicePixelRatio до 2. Координаты сцены остаются в CSS px.
- Во время штриха готовый фон/документ/предыдущие записи кэшируются; перерисовывается только активный штрих. После завершения кэш сбрасывается.
- Цвет и толщина ручки и маркера имеют независимые значения, сохраняются отдельно в браузере и явно отображаются на кнопках. Переключение больше не записывает значение общего picker в состояние предыдущего инструмента.
- Добавлена отдельная кнопка маркера на доске. Инструменты подписаны; основные кнопки и цветовые зоны имеют размер минимум 44 CSS px и touch-action:manipulation.
- Убрана случайная связь PDF-ввода с состоянием жестов доски; PDF обрабатывает только указатель, начавший штрих.

Проверки: общий набор лаборатории; браузерный ввод пера с нулевым нажимом, чёткое попадание медленных координат без отставания, отдельные цвета/толщина, восстановление настроек, размеры зон нажатия, сохранение PDF/проектов и жесты на доске при DPR=2.

Это программные проверки. Задержка Wacom/Sidecar/AirPlay и ощущения на физическом устройстве не измерены. Рабочие сайты не обновляются автоматически; текущий публичный sandbox остаётся на прежней установленной сборке.
