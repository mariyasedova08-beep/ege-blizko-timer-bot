# ЕГЭ БЛИЗКО — реакции обмена: системное расширение (черновик)

**Дата:** 22.10.2026. **Статус:** проверенная отдельная ветка, НЕ опубликовано в работающем боте.

## Почему потребовалось расширение

Раньше химическая база работала как конечный список вручную добавленных пар: известные примеры реагировали, а другие аналогичные вещества отображались как неописанные. Новая `ege_lab_exchange_matrix.py` формирует дополнительные проверяемые результаты для явного перечня **растворимых веществ** из `ege_lab_substances.py`. Источником типов и цветов служит общий реестр; не создаётся новая экспериментальная установка.

## Покрытие первой большой очереди

| Класс | Условие включения | Пример |
|---|---|---|
| Соль + соль | только реальное выпадение осадка по кураторской таблице растворимости | BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl |
| Соль + щёлочь | нерастворимый гидроксид и/или другая нерастворимая соль | CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄ |
| Кислота + щёлочь | нейтрализация с образованием воды; при необходимости осадок | 2HCl + Ca(OH)₂ → CaCl₂ + 2H₂O |
| Кислота + средняя/кислая соль | CO₂, SO₂ или H₂S при допустимых реагентах | NaHCO₃ + HCl → NaCl + CO₂↑ + H₂O |
| Кислота + соль | осадок с переносом ионов | BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl |
| Кислота + растворимый силикат | студенистый H₂SiO₃ | Na₂SiO₃ + 2HCl → 2NaCl + H₂SiO₃↓ |
| Соль аммония + щёлочь | NH₃ и H₂O | NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O |
| Совместный необратимый гидролиз | Al(III), Cr(III), Fe(III) с карбонатами; Al(III), Cr(III) также с сульфитами/сульфидами и соответствующими кислыми солями | 2AlCl₃ + 3Na₂CO₃ + 3H₂O → 2Al(OH)₃↓ + 3CO₂↑ + 6NaCl |
| Cu(II) + карбонаты | зелёный основной карбонат **Cu₂(OH)₂CO₃** и CO₂, а не CuCO₃ | 2CuSO₄ + 2K₂CO₃ + H₂O → Cu₂(OH)₂CO₃↓ + 2K₂SO₄ + CO₂↑ |
| Реакция не идёт | только безопасные смеси сильных растворимых электролитов без движущей силы | NaCl + KNO₃ |

Количество **новых кандидатов до исключения существующих ручных пар** автоматически выводится CI в `EXCHANGE_MATRIX_TOTAL`. В отчёте считать отдельно `p` (осадок), `g` (газ), `n` (нейтрализация), `x` (осадок и газ), `z` (нет реакции). **Не путать это число с количеством уникальных реакций реально опубликованной базы**: редакторские записи имеют приоритет, дубликаты удаляются при интеграции.

## Не подменять химические исключения

- Fe(III) + S²⁻/SO₃²⁻ или иодиды: **ОВР**, не обычный обмен/гидролиз; соответствующие реакции — в следующей предметной очереди замечания №2.
- Cu(II) + иодиды: **ОВР**, а не осадок обычного CuI₂.
- Cu(II) + карбонат: основная соль, не голубой Cu(OH)₂ и не средний CuCO₃.
- Al(III), Cr(III), Fe(III) с силикатами: не создавать фиктивные средние силикаты, требуют отдельной проверки совместного гидролиза.
- Кислые соли фосфорной кислоты, гидроксокомплексы Al/Zn/Cr, влияние избытка реактивов, растворимость при высокой ионной силе/концентрации, комплексообразование и температурные исключения требуют отдельного курирования.
- Ничего не выводить автоматически для неизвестной формулы или вещества, не отмеченного растворимым в реестре.
- Отсутствие результата **не означает**, что «реакция невозможна»; достоверное «реакция не идёт» показывать только для узко проверенных инертных пар.

## Проверки перед публикацией

- Каждый сгенерированный химический результат проходит автоматический подсчёт атомов с учётом скобок и нижних индексов.
- Тесты: AgCl, BaSO₄, PbI₂, Ag₂O, Fe(OH)₂, Fe(OH)₃, Al(OH)₃, Cr(OH)₃, Cu(OH)₂, основной карбонат меди, NH₃, CO₂, SO₂, H₂S, H₂SiO₃, безопасные смеси без обмена.
- Браузерный сценарий на реальном HTML лаборатории, в режимах PDF 30/70 на 920 и 1440 px.
- База Mn/Cr, все ранее вручную внесённые реакции и варианты с отдельной средой/избытком **имеют приоритет**.
- Проверить на настоящем Timeweb резервное копирование, локальные патчи и корректный отдельный защищённый релиз. **Ничего не обновлять без разрешения владельца.**

## Источники

Внутренняя база веществ `ege_lab_substances.py`, существующие реакции `ege_lab_inorganic_reactions.py`, а также предоставленный преподавателем конспект «Необратимый гидролиз — теория и реакции с записями» (страницы 18–24, 27–28). Формулы и условия из конспекта отдельно выверяются перед внесением и не должны механически подменяться похожими реакциями.
