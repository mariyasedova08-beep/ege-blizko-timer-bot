# Панель урока в одну строку — 02.11.2026

Подготовлено в изолированной ветке, на сервер ещё не установлено.

Открытие PDF, стрелки/счётчик страниц и инструменты письма/цвета/настройки расположены в одной непрерывной горизонтальной строке. На узкой панели прокручиваются только элементы управления; flex-start и min-width:0 не дают крайним кнопкам уходить за недоступный левый край. Размеры кнопок из компактной версии сохранены, для touch-first — 44px. Меню настроек фиксируется относительно окна и не обрезается скроллером; положение обновляется при открытии, изменении размеров и прокрутке. В режиме презентации во всё окно скрытая дублирующая кнопка разворачивания не занимает место; отдельный выход остаётся.

Химия, пробирки, сохранение записей и сам PDF не меняются. Обновление использует прежний sandbox-установщик с backup/health/откатом; production, nginx, сертификаты и базы не затрагиваются.
