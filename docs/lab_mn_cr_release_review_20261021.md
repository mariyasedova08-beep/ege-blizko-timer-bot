## Границы кандидатного выпуска
Серверный `ege_lab_webapp.py` уже отдаёт список `medium_reactions` в API `/lab-app/api`.
Подготовлено условное поле «Среда» в **основном режиме «PDF + опыт»**; оно появляется только у соответствующих пар.
Смена среды выбирает правильный результат из единого справочника, не подменяет другие условия, не показывает продукт до обязательного нагревания и не визуализирует четыре заблокированных случая.
18 новых веществ находятся в общем реестре.
Для самостоятельного режима **четырёх пробирок** тоже подготовлено условно появляющееся поле «Среда»: оно связано с тем же списком `medium_reactions`, а прежние обычные пары не меняются. При незаданной/неподтверждённой среде результат не моделируется; нагревание обязательно, когда оно указано. Перед выпуском нужен успешный тест именно этого режима на 920/1440 px и контроль прежних опытов.
PDF с записями обрабатывается в браузере, не должен добавляться в репозиторий или передаваться на сервер без отдельного дизайна прав доступа.
