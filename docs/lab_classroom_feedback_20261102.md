Статус: пакет установлен на тестовый Timeweb; общий GitHub CI и отдельные HTTPS/nginx-проверки успешны. Прямая внешняя HTTPS-проверка подтвердила build cf3e20fd49ed54ce и хеши. Независимые read-only SSH и публичные браузерные проверки успешно завершены. Production не изменялся.

## Выполнено

- Убран выпадающий список страниц презентации; стрелки и счётчик сохранены. Список закладок находился в том же элементе и тоже удалён; отдельного содержания пока нет.
- Более плотная аппроксимация кривых и мягкое пространственное сглаживание почерка без очереди/задержки ввода; реальные точки пера сохранены. Физическое удобство на Wacom оценивает преподаватель.
- Хлор: отдельная жёлто-зелёная анимация с минимальной непрозрачностью 0.7; более широкий шлейф и контрастные пузырьки. Бесцветным газам окраска не добавляется.
- KMnO₄ + HCl: добавлена прямая реакция с хлором, без отдельного выбора среды; HCl уже задаёт кислую среду.
- K₂MnO₄ и Na₂MnO₄: выбор среды в обоих режимах, отдельные варианты с соответствующими сульфитами. Кислая: Mn(II), исчезновение зелёной окраски. Нейтральная/щелочная: конечный MnO₂ при достаточном восстановителе; это не модель кинетики всех промежуточных форм и концентраций. Для K₂MnO₄ + HCl лишний выбор среды также убран; условие нагрева сохранено из каталога.
- Исправлена подпись импортированного MN-46: манганат зелёный, а не фиолетовый.
- В шапку только режима «Урок» добавлен существующий Кулёчек с небольшой розовой шапкой Деда Мороза. Изображение оптимизировано и встроено: внешние загрузки не требуются. Кабинеты детей/преподавателя не изменяются.

## Химическая основа

Нейтральная реакция K₂MnO₄ + K₂SO₃ + H₂O → MnO₂↓ + K₂SO₄ + 2KOH: официальный ключ CKE, май 2026, задание 8, страница 10:
https://cke.gov.pl/images/_EGZAMIN_MATURALNY_OD_2023/Arkusze_egzaminacyjne/2026/Chemia/MCHP-R0-100-2605-zasady.pdf

Кислый калиевый вариант выведен из импортированного натриевого MN-46 заменой катиона; баланс атомов проверяется автоматически. Щелочной вариант — конечное восстановление Mn(VI) до Mn(IV) с достаточным сульфитом, а не аналог восстановления перманганата до зелёного манганата.

Проверены прямой запуск кислоты, все четыре выбора среды манганата, осадок/отсутствие ложного газа, обратный порядок реагентов, независимые пробирки, PDF/доска, инструменты, рукопись, наличие изображения Кулёчка. Старые сценарии сохранены. Для PDF фикстуры используются разные имена по размеру экрана, чтобы сохранённая страница предыдущего сценария не меняла начало следующего.

Safari, физический Wacom/iMac и Zoom не проверены автоматически. Полнота всех заданий №6/№30 не заявляется.

## Изолированная установка и откат

Меняется только /var/lib/ege-lab-sandbox; перезапускается только ege-lab-sandbox-preview.service. Nginx/сертификаты повторно настраивать не требуется. Диагностический SSH остаётся read-only; выполнить установку агент через него не может. Установщик загружает точный commit и проверяет хеши, сохраняет backup, проверяет health и откатывается при ошибке.
