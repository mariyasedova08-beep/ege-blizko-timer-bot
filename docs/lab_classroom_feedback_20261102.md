- Исправлена подпись импортированного MN-46: манганат зелёный, а не фиолетовый.
- В шапку только режима «Урок» добавлен существующий Кулёчек с небольшой розовой шапкой Деда Мороза. Изображение оптимизировано и встроено: внешние загрузки не требуются. Кабинеты детей/преподавателя не изменяются.

## Химическая основа

Нейтральная реакция K₂MnO₄ + K₂SO₃ + H₂O → MnO₂↓ + K₂SO₄ + 2KOH: официальный ключ CKE, май 2026, задание 8, страница 10:
https://cke.gov.pl/images/_EGZAMIN_MATURALNY_OD_2023/Arkusze_egzaminacyjne/2026/Chemia/MCHP-R0-100-2605-zasady.pdf

Кислый калиевый вариант выведен из импортированного натриевого MN-46 заменой катиона; баланс атомов проверяется автоматически. Щелочной вариант — конечное восстановление Mn(VI) до Mn(IV) с достаточным сульфитом, а не аналог восстановления перманганата до зелёного манганата.

## Изолированная установка и откат

Меняется только /var/lib/ege-lab-sandbox; перезапускается только ege-lab-sandbox-preview.service. Nginx/сертификаты повторно настраивать не требуется. Диагностический SSH остаётся read-only; выполнить установку агент через него не может. Установщик загружает точный commit и проверяет хеши, сохраняет backup, проверяет health и откатывается при ошибке.

После установки нужны независимые read-only SSH и публичные HTTPS/браузерные проверки; до этого сайт не объявляется обновлённым. Сохранить проект перед перезагрузкой вкладки.

Откат: `python3 /var/lib/ege-lab-sandbox/installer.py --rollback`.
