# Ноябрь. Зима близко — кабинеты ЕГЭ БЛИЗКО

Поздняя осень, молочный фон #F8F5F2, пепельно-розовые поверхности,
чернильный текст и приглушённая малина #B63870. В шапке — голые ветви,
два опавших листа, лёгкий иней и оригинальная векторная иллюстрация Кулька
с большими стоячими ушами и шарфом. Без сугробов, ёлок, гирлянд и анимации.

Шапка обоих кабинетов: «Ноябрь · ЕГЭ БЛИЗКО», «Зима близко. ЕГЭ тоже.»
Для преподавателя: «Твой штаб подготовки. Всё важное — под рукой.»
Для ученика: «За окном прохладнее. В знаниях — больше уверенности.»
Изображение декоративное, не перекрывает кнопки; дополнительный декор только
на главной, рабочие карточки получают цветовую тему. Сохраняются смысловые
цвета статусов, привычные разделы, размер шрифта и навигация. Не применяется
новогодняя терминология, не меняются задания и сроки, в том числе октябрьские.

## Реализация

`ege_november_theme.css` — стили, ограниченные body.ege-november.
`ege_november_theme.js` — установка класса и декоративной шапки после top.
Повторные renderHome/render не создают дубликаты. MutationObserver сгруппирован
через requestAnimationFrame, не опрашивает API, не читает данные учеников,
не меняет обработчики, localStorage или сервер. Для учеников отслеживается
рендер вложенного view-home; для преподавателя — верхний уровень app.
Роль задаётся статическим data-cabinet-role, без нового определения доступа.
Иллюстрация встроена SVG; шрифты и картинки не загружаются с внешних сайтов.

`deploy/november_theme_patch.py` добавляет встроенный CSS в конец head и
декоративный script в конец body. Исходные HTML, inline-скрипты, API URL,
обработчики, дедлайны и тексты сохраняются байт-в-байт. Повторная установка
идемпотентна; несовпадающий установленный блок не перезаписывается.

## Проверено и ограничения

Четыре теста трансформации для обеих ролей: сохранение исходных скриптов и
разметки, повтор, конфликт существующей темы, неизвестная роль/структура.
Синтаксис JS проверяется Node `--check`. Скрипты из существующего публичного
HTML остаются неизменными. Мобильные стили предусмотрены для 320–480 px.

Интерактивный демонстрационный макет создан на основе CSS из GitHub; имена,
показатели и даты в нём вымышлены. Переключение роли/ширины не подключено к
реальным аккаунтам. Runtime браузерной визуальной проверки недоступен:
загрузка локального макета блокируется политикой cloud browser; отдельный
локальный Chromium не удалось скачать. Поэтому отсутствие переполнения,
реальные рендеры и нажатия в production пока не подтверждены.

## Перед публикацией

На VPS ранее были осенние изменения HTML, отсутствующие в GitHub. Не заменять
живые HTML целиком файлами из репозитория. Сначала read-only сверка двух
действующих HTML, включая осенний CSS и расположение top/view-home; проверить
совместимость и специфичность нового слоя. Затем зафиксировать хеши,
подготовить точечное добавление с резервными копиями владельца/прав и
откатом ровно этих блоков. Установка только после отдельного подтверждения
владельца; PR/push тему ученикам не включает.

Минимальная приёмка: главная преподавателя и ученика, переход и возврат из
всех вкладок без дубликата шапки, 320/390/760 px без горизонтальной прокрутки,
кнопки/фокус/контраст, старые статусы и даты, статистика и оплаты, повторная
загрузка и время ответа API без ухудшения. Прежний осенний CSS не удалять
вслепую: снять/ограничить только после анализа реального файла. Тема не
должна затронуть лабораторию, ПРЕПАДМИН и отправку уведомлений.
