# Полная химическая тестовая сборка — подготовка 01.11.2026

## Что подготовлено

Пакет preview/lab-sandbox/bundle.json содержит актуальные HTML режима «Урок» и свободных опытов, всю химическую базу: 219 веществ, 1423 записи реакций/условий, 89 вариантов со средой. Build: 286a6a6a3cff7105. SHA-256 пакета: 669d611d1c1eea7a15e0824da5fe1ed4395f363b0b68bed752feb14e5cd63800.

Это отдельная среда проверки интерфейса и химии. Она не импортирует run_bot, не читает SQLite, не вызывает Telegram и не сохраняет статистику бота. Экзаменационные банки и операции сохранения прогресса в бот не включены. Проекты доски, изображения, загруженные PDF и пометки остаются в браузере; сохранение проектов выполняется скачиванием файла. PDF.js/pdf-lib по-прежнему нужны в браузере с CDN.

На VPS запускается фиксированный Python-сервер стандартной библиотеки; он читает только упакованные HTML и JSON. Встроенные маршруты: GET /lab-app, GET /healthz, POST /lab-app/api (load и event). Нет произвольного доступа к файловой системе или выполнения кода из пакета.

## Установка и откат

Установщик deploy/bootstrap_lab_sandbox.py предназначен для одного запуска владельцем из доверенной root-консоли. Он скачивает только пакет и сервер из закреплённого GitHub commit и проверяет оба SHA-256 до конфигурации сервиса. Нет git pull, массового копирования файлов, pip install или запуска модулей бота на VPS.

Перед активацией сохраняются предыдущая ссылка current, unit и диагностический helper. При ошибке healthcheck выполняется откат этой тестовой установки. Сохраняются все старые releases и backups.

Ручной откат после установки:

```bash
python3 /var/lib/ege-lab-sandbox/installer.py --rollback
```

Он возвращает последнюю сохранённую тестовую версию, helper и состояние только тестового сервиса. Если до установки сервиса не было, новый сервис останавливается и его unit удаляется. Рабочие сервисы не перезапускаются.

## Текущее состояние и следующий этап

На момент подготовки установщик на Timeweb не запущен. Работа сервиса, поддержка ограничений systemd ядром VPS, реальный HTTP healthcheck и откат на самом VPS ещё не проверены. Успешная локальная проверка systemd-файла не является доказательством серверного запуска.

Диагностический доступ через GitHub уже успешно подключается к Timeweb и подтверждает старую сборку. После установки он сможет получить build и SHA нового пакета через фиксированный /healthz. Сам этот доступ не позволяет устанавливать новые сборки.

Публичный тестовый HTTPS-домен и проверка на физическом iPad/Safari — последующий этап. Публичные порты/firewall/nginx этим установщиком не меняются. Production-выпуск не выполнялся и не разрешён.
